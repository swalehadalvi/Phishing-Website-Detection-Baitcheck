# Phishing-Website-Detection-Baitcheck
Baitcheck is a browser-based phishing link checker. Paste a URL and get a 0 to 100 risk score with plain-language reasons. It checks 392,000 reported phishing domains, spots lookalike brands and URL tricks, and can read TLS certificates through an optional local helper. A Report fraud guide covers India’s 1930 helpline and cybercrime.gov.in.
